# 📡 DSP Spectral Signal Decoder & Custom FFT Engine

Инструмент цифровой обработки сигналов (DSP) для спектрального анализа многоканальных данных, полосовой фильтрации в частотной области и декодирования импульсных двоичных последовательностей. 

Ключевая особенность проекта — **собственная реализация алгоритма Быстрого Преобразования Фурье (БПФ)** без использования готовых математических библиотек (`scipy.fft` / `numpy.fft`).

---

## 📌 О проекте

Программа решает классическую задачу телекоммуникаций: выделение целевого информационного канала из зашумленного многоканального сигнала с частотным разделением (FDM) и последующее восстановление переданного 5-битного цифрового кода.

### Основные этапы пайплайна (Pipeline):
1. **Чтение бинарных данных:** чтение сырых IEEE 754 float-значений из бинарных файлов потоков (`struct.unpack`).
2. **Прямое БПФ (Custom Radix-2 FFT):** вычисление амплитудно-частотного спектра сигнала с дополнением нулями (zero-padding) до степени двойки ($N = 512$).
3. **Полосовая фильтрация (Frequency Filtering):** программная селекция выбранного частотного канала ($f_{\text{center}} = \text{channel} \times 40\text{ Гц} \pm 20\text{ Гц}$) с сохранением эрмитовой симметрии для вещественного спектра.
4. **Обратное БПФ (Custom IFFT):** восстановление временной формы сигнала отфильтрованного канала.
5. **Пороговое декодирование (Threshold Demodulation):** сегментация восстановленного сигнала и демодуляция 5-битного кода на основе амплитудного порога ($> 0.5\text{ В}$).

---

## 🧮 Алгоритмическое ядро: БПФ «с нуля»

Вместо применения готовых "черных ящиков" в проекте с нуля реализован классический алгоритм **Кули — Тьюки (Cooley-Tukey Radix-2 DIT FFT)** с вычислительной сложностью $\mathcal{O}(N \log N)$:

* **Битовая инверсия (Bit-Reversal Permutation):** эффективная перестановка элементов входного массива по алгоритму реверсирования двоичных разрядов индексов.
* **Каскады «бабочек» (Butterfly Operation):** поэтапное вычисление спектральных составляющих через комплексные поворотные коэффициенты (twiddle factors $W_N^k = e^{-j \frac{2\pi}{N} k}$).
* **Обратное преобразование (IFFT):** реализовано с инверсией фазовых множителей и последующей нормировкой на длину выборки $N$.

## 📊 Визуализация результатов

Программа строит 4 синхронизированных графика в **Matplotlib**:

1. **Временная область (Исходный сигнал):** суперпозиция несущих частот и шума.
2. **Частотная область (Полный спектр):** нормализованный амплитудный спектр всех каналов системы.
3. **Выделенный канал:** амплитудный спектр после применения полосового фильтра.
4. **Восстановленный сигнал и стробы:** временная форма отфильтрованного сигнала с наложенными порогами квантования ($+0.5\text{ В} / -0.5\text{ В}$) и итоговым декодированным кодом.

## 🚀 Запуск проекта локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/DamnKhis/dsp-spectral-signal-decoder.git
cd dsp-spectral-signal-decoder
```

### 2. Установка зависимостей
Для работы требуется только библиотека визуализации:
```bash
pip install matplotlib
```

### 3. Запуск анализа
Убедитесь, что бинарный файл с сигналом (например, `filekr5.dat`) находится в корневой папке скрипта.
```bash
python spectrum_analyzer.py
```

*Для смены анализируемого канала измените параметр `channel` в функции вызова:*
```python
# Запуск анализа для 4-го частотного канала (f_center = 160 Гц)
run_analysis("filekr5.dat", channel=4)
```
